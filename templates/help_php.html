PHP sites

PHP sites

A project with an index.php (and no app.py) is a PHP site. It runs in the student's own browser — PHP 8.4, compiled to WebAssembly — so there is no server to set up and nothing to install. Start one with Add to class → PHP site, or + PHP site in the editor.

Files

  • index.php is the page at /. Every other .php file at the top level is a page at its own address: about.php is /about.php.
  • includes/ holds the pieces pages share: include 'includes/header.php';
  • static/ holds stylesheets, scripts and pictures: <link rel="stylesheet" href="static/style.css">
  • schema.sql, if there is one, builds the database (below).

What works

  • echo, <?= ... ?>, variables, arrays, if, foreach, functions — all of PHP itself.
  • $_GET from the address (game.php?id=2) and $_POST from a form.
  • session_start() and $_SESSION: it lasts from page to page until the next ▶ Run.
  • header('Location: index.php'); exit; after a form. The preview follows it.
  • include and require.
  • password_hash and password_verify, htmlspecialchars, json_encode, and a page that answers JSON to the page's own fetch().
  • Warnings and errors show in the page, as on XAMPP, and in the console with the file and line. A page PHP can't read gets a card saying what is wrong, in plain words.

The database

Put CREATE TABLE and INSERT statements in schema.sql. Every ▶ Run builds data.db from it, from nothing — so anything a page adds is gone at the next Run. Pages open it with PDO:

$db = new PDO('sqlite:data.db');
$db->exec('PRAGMA foreign_keys = ON');
$stmt = $db->prepare('SELECT * FROM games WHERE id = ?');
$stmt->execute([$_GET['id']]);
$game = $stmt->fetch();

It is SQLite, not MySQL: a MySQL server can't run inside a browser. PDO code is the same for both except the connect line, so a lesson written for MySQL changes new PDO('mysql:host=…') to new PDO('sqlite:data.db'), and in schema.sql AUTO_INCREMENT becomes INTEGER PRIMARY KEY AUTOINCREMENT.

What doesn't

  • MySQL and mysqli_* — use PDO with SQLite.
  • File uploads ($_FILES), sending email, and reaching other websites from PHP.
  • A page that runs longer than 10 seconds is stopped, and the site starts again.
